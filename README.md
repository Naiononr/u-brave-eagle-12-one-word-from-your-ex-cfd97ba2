> unread

The one word your ex would use to describe you: the partner whose messages sat unread, the reply that never came. It is funny because a message status is handed down as a verdict on a whole person — nobody expects their character reference to read like a notification badge. It stings because it is true: everyone has been the unread message, or the one who left someone unread. Six plain letters, read in one glance, no explanation needed — and a near synonym like "ignored" loses the edge, because ignored is generic while unread is the specific modern wound, the message seen in the list and never opened.

## Run

```sh
node main.ts
```

Writes the word exactly, with no trailing newline, to `<MAKEFUN_OUTPUT_DIR or /output>/entry.txt`, mode 0644. Node 22.18 or later, standard library only, no network.
